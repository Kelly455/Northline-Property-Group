
# Northline Property Group

A responsive real estate website customized as a front-end development portfolio project. Northline Property Group is a fictional brand created to demonstrate website customization for the U.S. real estate market.

## About the Project

Northline Property Group showcases residential properties for sale and rent, property details, agent profiles, customer testimonials, and contact calls to action.

The website was customized from the Haven real estate starter template. The project focuses on adapting an existing website's visual identity, content, property listings, and interactive features.

## Features

- Responsive real estate homepage
- Property search and filtering controls
- Nine property listings
- Individual property detail pages
- Property favorites saved in browser storage
- Property image galleries where images are available
- Agent profiles and specialties
- Customer testimonial section
- Home valuation call to action
- Navigation links and contact information

## Built With

- HTML5
- CSS3
- Vanilla JavaScript
- Browser localStorage for saved favorites

## Project Structure

- `index.html` — Main homepage and property listings
- `listing.html` — Individual property detail page
- `assets/js/main.js` — Property data and interactive website functionality
- `assets/css/style.css` — Website styling
- `assets/` — Website images, stylesheets, and supporting assets
- `LICENSE` — Original template license
- `template.json` — Template metadata

## Running the Website Locally

1. Download or clone the project repository.
2. Open the project folder in Visual Studio Code.
3. Open `index.html` in a browser, or use the Live Server extension.
4. Test the property search, filters, favorites, navigation, and property detail pages.

Keep all supporting files and folders in their expected locations so image, stylesheet, and JavaScript paths continue to work.

## Current Limitations

- The home valuation form is a demonstration and is not connected to a live submission service.
- Some property listings still need their own appropriate interior gallery images.
- Sample agent profiles, testimonials, contact details, and property information are fictional.
- Careers and Privacy links may require dedicated pages before a production launch.
